# LargeHardLiteLauncher

[简体中文](README.md) | [English](README.en.md) | [Français](README.fr.md) | Русский | [微软式中文](README.zh-ms.md)

Лаунчер Minecraft, работающий в терминале. Написан на C# с использованием
[Terminal.Gui](https://github.com/gui-cs/Terminal.Gui), компилируется NativeAOT в один exe
без зависимости от среды выполнения .NET и без графического интерфейса.

Раскладка повторяет [PCL2](https://github.com/Hex-Dragon/PCL2), сетевая часть — реализацию
Terracotta из [HMCL](https://github.com/HMCL-dev/HMCL).

## Возможности

**Запуск**

- Несколько каталогов игры, список версий сортируется по числовым сегментам
- Настройки для каждой версии: режим памяти, Java, аргументы JVM, аргументы игры, размер
  окна, режим изоляции, команда перед запуском
- Отсутствующие библиотеки скачиваются автоматически перед запуском (с переходом на зеркало);
  нехватка библиотеки больше не блокирует запуск
- Java выбирается как минимальная подходящая мажорная версия; для 32-битной Java объём кучи
  снижается, выводится предупреждение
- Процесс игры создаётся с флагом `DETACHED_PROCESS`, поэтому закрытие окна терминала не
  завершает игру
- Сессия записывается в `running-game.json`; при повторном запуске лаунчер распознаёт
  работающую игру
- Анализ падений сопоставляет признаки журнала с причиной и рекомендацией (14 правил)
- Настраиваемая главная страница: предустановленный текст, локальный файл или удалённый URL,
  с подстановками `${date}` `${player}` `${version}` и другими

**Загрузка и установка**

- Установка ванильной игры, выбор источника (официальный / зеркало BMCLAPI / автоматически)
- Установка загрузчиков: Forge, NeoForge, Fabric, Quilt
- Поиск и установка ресурсов сообщества: моды, сборки, датапаки, наборы ресурсов, шейдеры
  (Modrinth без ключа; для CurseForge нужен свой ключ)
- Докачка при обрыве: при сетевой ошибке файл `.tmp` сохраняется для следующей попытки,
  удаляется только при несовпадении контрольной суммы
- Обязательные зависимости скачиваются вместе с модом
- Установка сборок (`.mrpack`): ставит соответствующий загрузчик и распаковывает overrides
- Экспорт версии в `.mrpack` с необязательным онлайн-сопоставлением для уменьшения размера
  (измерено: сборка из 62 модов сократилась с 518 МБ до 186 МБ)

**Управление версиями**

- Менеджер модов: сканирование каталога mods, групповое включение и отключение
  (переименование в `.disabled`), удаление, проверка обновлений
- Проверка обновлений модов: поиск последней версии на Modrinth по SHA1 файла jar,
  обновление одним действием
- Управление наборами ресурсов и шейдерами: чтение и запись фактического состояния
  включения в `options.txt` и `optionsshaders.txt`
- Проверка файлов: сверка клиентского jar, библиотек, natives и ресурсов с json версии
- Удаление версии (вместе с сохранениями и настройками)

**Сетевая игра**

- Terracotta встроена; создание и подключение к комнате без отдельной загрузки
- Список публичных узлов-ретрансляторов загружается автоматически

**Запуск JAR**

- Самостоятельный запуск любого jar (сервер, клиент или другая программа на Java)
- Настройка памяти, профилей сборщика мусора (G1 / ZGC / Parallel / Serial), дополнительных
  аргументов JVM и программы, режима сервера
- Поле команды отправляет ввод напрямую в стандартный ввод процесса
- Путь к jar в командной строке или перетаскивание jar на exe сразу открывает эту страницу

## Интерфейс

Шесть страниц, переключение по F1–F6:

```
Запуск | Загрузка | Сеть | JAR | Настройки | Ещё
```

- **Запуск**: учётная запись, список версий, кнопка запуска, главная область
- **Загрузка**: ванильная игра, загрузчики, ресурсы сообщества
- **Сеть**: создание и подключение к комнатам
- **JAR**: самостоятельный запуск jar
- **Настройки**: учётная запись, Java, память, изоляция, источник загрузки, оформление,
  производительность
- **Ещё**: руководства, благодарности, небольшие инструменты (включая эхо-колодец, питаемый
  веткой Discussions)

## Требования

- Windows 10 или новее (создание процессов и перечисление окон используют Win32 API)
- Для запуска игры нужна Java либо скачайте её в разделе «Настройки → Java»
- Рекомендуется терминал шириной от 100 столбцов, минимум 80

## Сборка

Требуются .NET 10 SDK и набор инструментов MSVC (используется компоновщиком NativeAOT).

```bash
python scripts/build.py build      # сборка Debug, сохраняются все точки входа автотестов
python scripts/build.py publish    # публикация Release, результат в bin/Release/net10.0/win-x64/publish/
```

`scripts/build.py` делает три вещи: пропускает restore, очищает переменные окружения MSYS и добавляет
`IlcUseEnvironmentalTools` (чтобы ILCompiler использовал инструменты из окружения, а не искал
Visual Studio через реестр).

В сборке Debug есть точки входа автотестов, в Release их нет:

```bash
LargeHardLiteLauncher.exe --uitest        # создание всех шести страниц
LargeHardLiteLauncher.exe --selftest      # 31 блок проверок (нельзя запускать на AOT-сборке)
LargeHardLiteLauncher.exe --vmtest        # навигация менеджера версий
LargeHardLiteLauncher.exe --packcfgtest   # чтение и запись настроек наборов ресурсов
LargeHardLiteLauncher.exe --updatetest <каталог версии>   # проверка обновлений модов
LargeHardLiteLauncher.exe --launchtest <каталог версии>   # запуск игры с отслеживанием журнала
```

## Данные и настройки

```
%USERPROFILE%\.largehardlitelauncher\
  config.json         общие настройки
  logs\               журналы лаунчера
  java\               Java, скачанная лаунчером
  terracotta\         распакованное ядро сетевой игры
  cache\              кэш главной страницы
  running-game.json   текущая запущенная игра
```

Файлы игры и версии остаются в каталоге `.minecraft` и не изменяются.

## Известные ограничения

- Только Windows, переносов на другие платформы не планируется (создание процессов и поиск
  окон зависят от Win32)
- Проверка обновлений модов охватывает только Modrinth; API отпечатков CurseForge требует ключа
  и строго ограничивает частоту запросов
- Лаунчер не обновляет сам себя; для смены версии нужно заменить exe
- Работает в одном экземпляре; второй запуск только показывает сообщение
- Импорт сборок поддерживает только `.mrpack`, zip-сборки CurseForge не поддерживаются
- Эхо-колодец читает GitHub Discussions через точку доступа, отсутствующую в официальной
  документации REST (60 запросов/час анонимно); при сбое откат к кэшу и встроенным фразам

## Частые вопросы

**Почему интерфейс в терминале?**

Лаунчер Minecraft основное время тратит на загрузку, распаковку и сборку аргументов;
интерфейс лишь показывает результат. Графическому интерфейсу дополнительно нужны масштабирование
DPI, тёмная тема, высокий контраст, средства чтения с экрана и подстановка шрифтов. Терминал
избавляет от этого слоя и работает удалённо через ssh.

**Почему 24 МБ, если PCL занимает 5 МБ?**

Сравнение некорректно. PCL зависит от установленной в системе среды .NET Desktop Runtime
(сотни МБ) и содержит только прикладной код. Этот проект самодостаточен: вся среда выполнения
внутри, плюс 7,75 МБ встроенного ядра сетевой игры. При равных условиях прикладной код
составляет около 158 КБ.

**Удаляет ли он мои сохранения?**

Нет. Единственная функция, удаляющая файлы, — «Удалить версию»; она запрашивает подтверждение
и указывает, что действие необратимо. Отключение мода переименовывает файл; отключение набора
ресурсов или шейдера меняет только одну строку в `options.txt`.

## Сторонние компоненты

| Компонент | Назначение | Лицензия |
|---|---|---|
| [Terminal.Gui](https://github.com/gui-cs/Terminal.Gui) | терминальный UI-фреймворк | MIT |
| [Terracotta](https://github.com/burningtnt/Terracotta) | ядро сетевой игры, распространяется встроенным | AGPL-3.0 |
| [EasyTier](https://easytier.cn) | P2P-сеть под Terracotta | Apache-2.0 |

Двоичный файл Terracotta не изменён, его исходный код находится в вышестоящем репозитории.
Полный текст лицензии доступен в программе: «Ещё → О программе».

Данные загрузок и ресурсов получены из [BMCLAPI](https://bmclapi2.bangbang93.com),
[Modrinth](https://modrinth.com), [CurseForge](https://www.curseforge.com) и
[Adoptium](https://adoptium.net); китайские названия модов взяты с
[MCMod](https://www.mcmod.cn).
